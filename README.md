# TPQ NUR FATIMAH DIGITAL RELIGIUS

Aplikasi administrasi khusus TPQ Nur Fatimah.

## Status
Versi fondasi 0.1 (prototipe). Dashboard dan CRUD data santri, guru, serta kelas tersedia. Data saat ini tersimpan di localStorage browser. Belum siap untuk data operasional penting: autentikasi, Supabase/RLS, backup, absensi QR, keuangan, surat, akademik, dan laporan masih harus dibangun serta diuji.

## Menjalankan
Buka `index.html` melalui browser atau aktifkan GitHub Pages dari Settings → Pages → Deploy from a branch → main → /(root).

## Rencana
1. Autentikasi dan Supabase dengan RLS.
2. Master data santri, wali, guru, kelas, tahun ajaran.
3. Absensi QR guru dan santri.
4. Keuangan, pembayaran, kas, tunggakan, kuitansi.
5. Generator surat dan pencetakan.
6. Akademik, rapor, laporan, ekspor.
7. Backup, audit log, dan pengujian lintas perangkat.

Jangan memasukkan data pribadi/keuangan nyata sebelum kontrol keamanan dan database cloud selesai.
